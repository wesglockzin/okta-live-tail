# Okta Live Tail — how to use

1. **Pick an org.** Events start streaming within a few seconds.
2. **Type a filter** — a user, app name, app id or OAuth client id — to narrow the stream.
3. **Click a row** to see the raw System Log event.
4. Failures and Okta-internal events are shown on purpose; that is usually what you are debugging.

Read-only: the tool never writes to Okta.
